## 1. Eight variables from a shopping or food app
| Variable | Type | Reason |
|---|---|---|
| Product price | Numerical | It is measured as a number. |
| Number of likes | Numerical | It is a count. |
| Delivery time in minutes | Numerical | It is measured numerically. |
| Customer rating | Numerical | It is represented by a number. |
| Restaurant name | Categorical | It identifies a group or name. |
| Payment method | Categorical | It can be UPI, card, or cash. |
| Product category | Categorical | It can be clothing, food, or electronics. |
| Order status | Categorical | It can be delivered, pending, or cancelled. |

## 2. Two app features to analyse
1. **Restaurant ratings:** numerical data can show average ratings and help users compare restaurants.
2. **Payment method:** categorical data can show which payment options customers use most often and help the app improve checkout.
